# รอบ 4 — ตรวจทุกเมนูหลังบ้าน + เติมส่วนที่ขาด (เริ่ม 2026-11-03)

วิธีตรวจ: เปิดทุกหน้าในหลังบ้าน 57 หน้า (รวมหน้ารายละเอียด) ด้วยเบราว์เซอร์อัตโนมัติ ที่จอ 1366 px และ 390 px
แล้วบันทึกสถานะ HTTP, error ใน console และการล้นแนวนอน พร้อมจับภาพทุกหน้ามาเทียบกันด้วยตา

ผลตรวจรอบแรก: ทุกหน้าโหลดได้ (200) ไม่มี error · ล้นจอ 1 หน้า (แก้ไขสไลด์) · ตารางสินค้าที่จอ 1366 โดนตัดคอลัมน์ขวา ·
หลายตารางยังไม่มีปุ่มจัดการแบบเดียวกับหน้าสินค้า/เอกสารขาย และยังไม่มีค้นหา/แบ่งหน้า

## ล็อตถัดไป (ข้อเสนอ — รอเจ้าของร้านเลือก)

เมนูที่ยังไม่มี และถ้าไม่มีระบบจะยังไม่ครบสำหรับร้านที่ขายจริง:

| ล็อต | เมนู | ทำไมต้องมี |
|---|---|---|
| 14 ☑ | **ลูกหนี้ค้างชำระ** (แยกอายุหนี้ 0–30 / 31–60 / 61–90 / 90+ วัน ต่อรายลูกค้า, ส่งลิงก์ทวง, CSV) | ตอนนี้ต้องเปิดใบแจ้งหนี้ทีละใบเพื่อดูว่าใครค้างเท่าไร |
| 14 ☑ | **สรุปรับเงินประจำวัน / ปิดยอด** (รวมตามวิธีชำระ: โอน สลิป เงินสด COD · เทียบยอดเข้าบัญชี) | ไว้ตรวจว่าเงินเข้าครบทุกวัน |
| 15 ☑ | **ผู้ขาย (ซัพพลายเออร์)** — ทะเบียนผู้ขาย ผูกกับใบสั่งซื้อ ประวัติการสั่งและราคาทุน | ใบสั่งซื้อตอนนี้พิมพ์ชื่อผู้ขายเองทุกครั้ง |
| 15 ☑ | **นับสต็อกทั้งร้าน** (กรอกยอดนับหลายรายการพร้อมกัน → ปรับยอดทีเดียว มีประวัติ) | ตอนนี้ปรับได้ทีละรายการ |
| 16 | **ใบลดหนี้ / คืนเงิน** (อ้างอิงใบเสร็จเดิม ใช้กับคืนสินค้า/ลดราคาหลังขาย, รองรับ VAT) | เคลมแบบคืนเงินยังไม่มีเอกสารรองรับ |
| 16 | **คู่มือการใช้งานในหลังบ้าน** (ทีละขั้น: รับออเดอร์ → ตรวจสลิป → ส่งของ, ออกเอกสาร, ตั้งค่า) | เจ้าของร้าน/พนักงานใหม่เรียนรู้เองได้ |
