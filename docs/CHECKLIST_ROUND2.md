# รอบที่ 2 — 60 ข้อ (หน้าบ้าน 30 · หลังบ้าน 30)

แบ่งเป็น 4 ล็อต ทำพร้อมกัน แล้วตรวจซ้ำ (AI Recheck) อีกรอบ · สถานะ: ☐ ยังไม่ทำ · ☑ เสร็จ + ทดสอบแล้ว

## หน้าบ้าน (ลูกค้า)

### ล็อต 1 — สินค้า ค้นหา SEO ความเร็ว (U1–U15)
| # | งาน | เกณฑ์ผ่าน |
|---|---|---|
| U1 | ☑ Product JSON-LD ครบ (name, sku, image[], description, brand, offers: price/THB/availability/url, itemCondition) | ผ่าน schema ไม่มีฟิลด์ว่าง/URL สัมพัทธ์ |
| U2 | ☑ BreadcrumbList JSON-LD บนหน้าสินค้าและหมวด + breadcrumb ที่มองเห็นตรงกัน | URL เต็ม |
| U3 | ☑ แกลเลอรีรูปสินค้า: ปัดได้บนมือถือ, กดขยายเต็มจอ (lightbox) ปิดด้วย Esc/ปัด, ปุ่มก่อน/ถัดไป, คีย์บอร์ด | ใช้ได้ทั้ง mouse/touch/keyboard |
| U4 | ☑ รูปทุกที่มี width/height (กัน layout เลื่อน), lazy-load นอกจอ, decoding async, รูปแรกของหน้าสินค้า fetchpriority=high | ไม่มี CLS จากรูป |
| U5 | ☑ ตัวเลือกจำนวนบนหน้าสินค้า (− / + / พิมพ์) จำกัดตามสต็อก แสดง "เหลือ n ชิ้น" เมื่อ ≤ 5 | ใส่เกินสต็อกไม่ได้ |
| U6 | ☑ แถบ "ใส่ตะกร้า" ติดล่างจอบนมือถือ (sticky) เมื่อเลื่อนผ่านปุ่มหลัก | ไม่บังเนื้อหา/ปุ่ม LINE |
| U7 | ☑ สินค้าราคา 0 = "สอบถามราคา": ปุ่ม LINE พร้อมข้อความชื่อสินค้า + รหัส ส่งไปให้ร้าน | ลิงก์ LINE OA ถูกต้อง |
| U8 | ☑ "ซื้อคู่กัน" บนหน้าสินค้า: หม้อแปลง/ท่อหด/คอนโทรลเลอร์ ที่เข้ากัน + สินค้าในหมวดเดียวกัน | ไม่แสดงสินค้าปิดขาย |
| U9 | ☑ สินค้าที่ดูล่าสุด (เก็บในเครื่อง ≤ 8 ชิ้น) แสดงในหน้าสินค้า/ตะกร้าว่าง | ไม่ใช้คุกกี้ติดตาม |
| U10 | ☑ ค้นหา: รองรับคำไม่เต็ม/เว้นวรรคต่าง/ตัวพิมพ์เล็กใหญ่/รหัสสินค้า, แสดงจำนวนผล, ไม่พบ → คำแนะนำ + หมวดยอดนิยม + ปุ่ม LINE | ค้น "ไฟสระ", "rgb", "DL1" เจอ |
| U11 | ☑ หน้าหมวด: เรียงตาม (แนะนำ/ราคาต่ำ-สูง/สูง-ต่ำ/ขายดี/ใหม่) + กรอง (การใช้งาน/สี/ช่วงราคา/มีของ) เก็บใน URL, ปุ่มล้างตัวกรอง, จำนวนผล | กดย้อนกลับได้ |
| U12 | ☑ Open Graph/Twitter ของหมวด (รูปสินค้าแรก) + meta description ทุกหน้า + canonical ไม่มี query | ไม่มีหน้าใดไม่มี description |
| U13 | ☑ redirect 301 URL เก่าของ WordPress ที่เหลือ: /?p=, /?product=, /tag/*, /page/*, /category/* (บทความ), /feed, /wp-* → หน้าที่ใกล้ที่สุด (ไม่ใช่ 404) | ทดสอบทุกรูปแบบ |
| U14 | ☑ Web app manifest + ไอคอน (favicon, apple-touch-icon 180, 192/512) + theme-color สีร้าน | Lighthouse installable |
| U15 | ☑ Accessibility: skip-link, focus ที่มองเห็น, aria ของ drawer/ตะกร้า/เมนู, ตรวจด้วย axe ใน e2e ไม่มี violation ระดับ serious/critical บนหน้าหลัก | e2e axe ผ่าน |

| ☑ U20 | ขอใบกำกับภาษีตอนสั่งซื้อ: ชื่อบริษัท/บุคคล เลขผู้เสียภาษี (ตรวจ checksum) สาขา ที่อยู่ออกบิล → เก็บกับคำสั่งซื้อ และใช้ตอนออกใบเสร็จ | หลังบ้านเห็นข้อมูลนี้ |
| ☑ U21 | ย่อรูปสลิปในเบราว์เซอร์ก่อนอัปโหลด (รูปจากมือถือ 8–12 MB → ≤ 1.5 MB) + แสดงตัวอย่าง + แถบความคืบหน้า | สลิปใหญ่แนบได้ |
| ☑ U22 | หน้าสั่งซื้อสำเร็จ: สรุปคำสั่งซื้อ, ช่องทางโอน, คัดลอกเลขบัญชี/ยอด, ปุ่มบันทึกเป็นรูป/พิมพ์, ลิงก์ติดตาม | พิมพ์ได้สวย |
| ☑ U23 | หน้าติดตาม: ไทม์ไลน์สถานะ, เลขพัสดุ + ลิงก์ติดตามของขนส่ง (Kerry/Flash/ไปรษณีย์/J&T), ดาวน์โหลดใบเสร็จ (เมื่อออกแล้ว) | ต้องยืนยันด้วยเบอร์โทร |
| ☑ U24 | ใบเสร็จฝั่งลูกค้า `/track/receipt/[docId]?t=token` (ลิงก์มีโทเคนลับ, ไม่เดาได้) ใช้หน้าพิมพ์ A4 เดียวกับหลังบ้าน | ไม่มีโทเคน = 404 |
| ☑ U25 | ฟอร์ม "ขอใบเสนอราคา/ปรึกษา" (`/quote`): ชื่อ เบอร์ บริษัท รายละเอียดงาน แนบรูปพื้นที่ (≤ 3 รูป) รายการสินค้าจากตะกร้า → บันทึกเป็น Inquiry + แจ้ง LINE ร้าน | กันสแปม (honeypot + จำกัดครั้ง) |
| ☑ U26 | หน้า "ติดต่อเรา" (`/contact`): ที่อยู่ เวลาทำการ โทร LINE อีเมล แผนที่ (ลิงก์ Google Maps), ฟอร์มติดต่อ (Inquiry ชนิด CONTACT) | ข้อมูลจากตั้งค่าร้าน |
| ☑ U27 | หน้า "คำถามที่พบบ่อย" (`/faq`) จากเนื้อหาที่แก้ในหลังบ้าน + FAQPage JSON-LD | ไม่มีเนื้อหา = ซ่อนเมนู |
| ☑ U28 | หน้า "วิธีสั่งซื้อ/ชำระเงิน" (`/how-to-order`) และ "เกี่ยวกับเรา" (`/about`) จากเนื้อหาที่แก้ได้ | ลิงก์ในเมนู/ท้ายเว็บถูกต้อง |
| ☑ U29 | Analytics ตามความยินยอม: โหลด GA4/Meta Pixel (รหัสจากตั้งค่า) เฉพาะเมื่อลูกค้ายอมรับคุกกี้วิเคราะห์/การตลาด, ส่ง event view_item/add_to_cart/begin_checkout/purchase | ไม่ยินยอม = ไม่มีสคริปต์ภายนอก |
| ☑ U30 | แถบประกาศด้านบน (ข้อความ/ลิงก์/เปิด-ปิด จากหลังบ้าน) แทนข้อความตายตัว | ปิดแล้วไม่แสดง |
