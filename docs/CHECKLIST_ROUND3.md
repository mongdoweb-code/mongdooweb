# รอบ 3 — 60 ข้อ (ร่าง รอเจ้าของร้านยืนยัน)

หน้าบ้าน 30 ข้อ (U1–U30) + หลังบ้าน 30 ข้อ (A1–A30) แบ่ง 4 ล็อต ทำแบบละเอียด แล้ว AI ตรวจซ้ำทุกข้อ
ทุกข้อต้องมี e2e ที่ผ่านทั้งบนฐานข้อมูลใหม่ (CI) และสำเนาข้อมูลจริง · เงินเป็นสตางค์ คำนวณที่เซิร์ฟเวอร์เท่านั้น

## หน้าบ้าน (ลูกค้า)

### ล็อต 5 — แคตตาล็อกและการขาย (U1–U15)
| # | งาน |
|---|---|
| ☑ U1 | สินค้าหลายตัวเลือก (สี/วัตต์/ขนาด) รวมในหน้าเดียว: ปุ่มเลือกตัวเลือก, ราคา/รูป/สต็อกเปลี่ยนตาม, URL ต่อตัวเลือก, canonical ชี้หน้าหลัก |
| ☑ U2 | คูปองส่วนลดตอนชำระเงิน: ลด %/บาท, ยอดขั้นต่ำ, วันหมดอายุ, จำนวนครั้ง, จำกัดต่อเบอร์, เฉพาะหมวด — ตรวจที่เซิร์ฟเวอร์ แสดงในคำสั่งซื้อ/ใบเสร็จ |
| ☑ U3 | ราคาลดตามช่วงเวลา: ป้าย "ลด x%", ราคาเดิมขีดฆ่า, นับถอยหลังบนหน้าสินค้า, หมดเวลาแล้วกลับราคาปกติเอง |
| ☑ U4 | รีวิวสินค้าจากผู้ซื้อจริง (เลขคำสั่งซื้อ + เบอร์): ดาว ข้อความ รูป → รอแอดมินอนุมัติ · คะแนนเฉลี่ย + AggregateRating JSON-LD |
| ☑ U5 | เปรียบเทียบสินค้า (สูงสุด 4 ชิ้น): ตารางสเปกเทียบกัน แชร์ลิงก์ได้ |
| ☑ U6 | สเปกสินค้าแบบมีโครงสร้าง (IP, แรงดัน, วัตต์, อุณหภูมิสี, มุมแสง, วัสดุ) แสดงเป็นตาราง + กรองตามสเปกในหน้าหมวด |
| ☑ U7 | รายการโปรด (เก็บในเครื่อง) + แชร์เป็นลิงก์ / ส่งทาง LINE เพื่อขอใบเสนอราคา |
| ☑ U8 | เครื่องคำนวณหม้อแปลง: ใส่จำนวนโคม × วัตต์ → แนะนำหม้อแปลงที่เหมาะ (วัตต์รวม × 1.2) พร้อมปุ่มใส่ตะกร้า |
| ☑ U9 | แจ้งเมื่อมีของ: สินค้าหมดให้ฝากเบอร์/LINE → ร้านเห็นรายชื่อ + แจ้งเตือน LINE ร้านเมื่อเติมสต็อก |
| ☑ U10 | ราคาขายส่งตามจำนวน (เช่น 10 ชิ้นขึ้นไปลด) แสดงบนหน้าสินค้า คิดในตะกร้าที่เซิร์ฟเวอร์ |
| ☑ U11 | ไฟล์ดาวน์โหลดต่อสินค้า (สเปกชีต/คู่มือ PDF) |
| ☑ U12 | หน้าผลงานติดตั้ง (`/projects`): รูปงานจริงแยกประเภท + สินค้าที่ใช้ในงานนั้น |
| ☑ U13 | บทความ (`/blog`): หน้ารวม/หน้าบทความ, SEO ครบ, สินค้าที่เกี่ยวข้อง, redirect บทความเดิมจาก WordPress |
| ☑ U14 | ความเร็ว: รูปหลายขนาด (srcset) + WebP/AVIF, LCP < 2.5 วิ บนมือถือ, Lighthouse มือถือ ≥ 90 ที่หน้าแรก/หมวด/สินค้า |
| ☑ U15 | ค้นหาฉลาดขึ้น: คำพ้อง ไทย/อังกฤษ (ไฟใต้น้ำ = underwater), พิมพ์ผิดเล็กน้อยยังเจอ, บันทึกคำที่ค้นแล้วไม่เจอ |

### ล็อต 6 — หลังการขายและการชำระเงิน (U16–U30)
| # | งาน |
|---|---|
| ☑ U16 | แจ้งเคลม/ประกัน (`/claim`): เลขคำสั่งซื้อ + เบอร์ + สินค้า + รูป/อาการ → ตรวจว่ายังอยู่ในประกัน 1 ปี |
| ☑ U17 | ขอคืน/เปลี่ยนสินค้าภายใน 7 วัน (เสียหายจากขนส่ง) จากหน้าติดตาม |
| ☑ U18 | ลูกค้ายกเลิกคำสั่งซื้อเองได้ก่อนชำระเงิน (จากหน้าติดตาม) |
| ☑ U19 | แนบสลิปเพิ่ม (โอนหลายครั้ง/โอนขาด) รวมยอดหลายสลิป |
| ☑ U20 | เก็บเงินปลายทาง (COD) เป็นตัวเลือก: เปิด/ปิด, ค่าธรรมเนียม, ยอดสูงสุด, ไม่ต้องแนบสลิป |
| ☑ U21 | ค่าส่งพื้นที่ห่างไกล (ตามรหัสไปรษณีย์) + ค่าส่งตามน้ำหนัก/ขนาด (สินค้าชิ้นใหญ่) |
| ☑ U22 | รับสินค้าที่ร้าน เลือกได้ตอนชำระเงิน (ไม่คิดค่าส่ง) พร้อมเวลาเปิดร้าน |
| ☑ U23 | อีเมลแจ้งลูกค้า (รับคำสั่งซื้อ/ชำระแล้ว/จัดส่ง พร้อมเลขพัสดุ) ผ่าน SMTP — เปิดใช้เมื่อร้านตั้งค่า |
| ☑ U24 | ดาวน์โหลด/พิมพ์ใบสั่งซื้อ (PDF) จากหน้าสั่งซื้อสำเร็จและหน้าติดตาม |
| ☑ U25 | ลูกค้ายืนยันใบเสนอราคาออนไลน์ (ลิงก์ลับ) → ร้านได้แจ้งเตือน + สร้างใบแจ้งหนี้ |
| ☑ U26 | ชำระใบแจ้งหนี้ออนไลน์ (ลิงก์ลับ): QR พร้อมเพย์ยอดคงค้าง + แนบสลิป → รอร้านตรวจ |
| ☑ U27 | ปุ่มแชท LINE พร้อมบริบท (ชื่อสินค้า/เลขคำสั่งซื้อ) + สถานะ "ร้านเปิดอยู่/ปิดแล้ว" ตามเวลาทำการ |
| ☑ U28 | PDPA: ความยินยอมแยกประเภท (วิเคราะห์/การตลาด) + แบบฟอร์มขอดู/ลบข้อมูลส่วนบุคคล |
| ☑ U29 | ใช้งานได้แม้เน็ตไม่ดี: หน้าออฟไลน์, อัปโหลดสลิปลองใหม่อัตโนมัติ, ตะกร้าไม่หาย |
| ☑ U30 | ความน่าเชื่อถือบนหน้าแรก: คะแนนรีวิวรวม, โลโก้ลูกค้าองค์กร, จำนวนงานติดตั้ง (แก้ได้ในหลังบ้าน) |

## หลังบ้าน (ผู้ดูแลระบบ)

### ล็อต 7 — สินค้า โปรโมชัน เนื้อหา (A1–A15)
| # | งาน |
|---|---|
| ☑ A1 | จัดการตัวเลือกสินค้า (U1): รวมสินค้าเป็นกลุ่ม, ชื่อ/ค่าตัวเลือก, แก้ราคาหลายตัวพร้อมกัน |
| ☑ A2 | จัดการคูปอง (U2): สร้าง/ปิด/แก้, รายงานการใช้ |
| ☑ A3 | ตั้งเวลาลดราคา (U3) รายสินค้าและทั้งหมวด |
| ☑ A4 | ตรวจรีวิว (U4): อนุมัติ/ซ่อน/ตอบกลับ |
| ☑ A5 | กำหนดสเปกต่อหมวด (U6): ชื่อสเปก หน่วย ใช้เป็นตัวกรองหรือไม่ |
| ☑ A6 | ตั้งราคาขายส่งตามจำนวน (U10) |
| ☑ A7 | รายชื่อรอสินค้าเข้า (U9) + ส่งออก + ทำเครื่องหมายแจ้งแล้ว |
| ☑ A8 | อัปโหลดไฟล์ดาวน์โหลดของสินค้า (U11) |
| ☑ A9 | จัดการผลงานติดตั้ง (U12) |
| ☑ A10 | จัดการบทความ (U13): ร่าง/เผยแพร่/ตั้งเวลา, รูปปก, SEO |
| ☑ A11 | คำพ้องสำหรับค้นหา + รายงานคำที่ค้นไม่เจอ (U15) |
| ☑ A12 | แก้สินค้าหลายรายการพร้อมกัน: หมวด, ราคา ±%, เปิด/ปิดขาย |
| ☑ A13 | SEO รายสินค้า: แก้ title/description, แก้ slug แล้ว redirect 301 จากลิงก์เดิมอัตโนมัติ |
| ☑ A14 | จัดการ redirect เอง + บันทึกหน้า 404 ที่ถูกเรียกบ่อย → สร้าง redirect ได้ในคลิกเดียว |
| ☑ A15 | ตรวจรูปสินค้า: หารูปหาย/เสีย, สร้างรูปย่อใหม่ (สำหรับ U14) |

### ล็อต 8 — งานหลังการขาย การเงิน การดำเนินงาน (A16–A30)
| # | งาน |
|---|---|
| ☑ A16 | คิวเคลม/คืนสินค้า (U16/U17): สถานะ, เลข RMA, ผูกคำสั่งซื้อ, แจ้ง LINE ร้าน |
| ☑ A17 | คำสั่งซื้อ COD (U20): ยืนยัน, กระทบยอดเงินที่ขนส่งโอนคืน |
| ☑ A18 | ตั้งค่าพื้นที่ห่างไกล/น้ำหนัก (U21) และรับที่ร้าน (U22) |
| ☑ A19 | ตั้งค่า SMTP + แม่แบบอีเมล + ปุ่มส่งทดสอบ (U23) |
| ☑ A20 | สลิปจากลิงก์ใบแจ้งหนี้ (U26) เข้าคิวตรวจ → อนุมัติแล้วออกใบเสร็จอัตโนมัติ |
| ☑ A21 | ใบสั่งซื้อถึงผู้ขาย (PO) → รับของเข้า (เพิ่มสต็อก + ต้นทุน) |
| ☑ A22 | ต้นทุนสินค้า + รายงานกำไรตามสินค้า/หมวด/เดือน |
| ☑ A23 | กลุ่มลูกค้า: แท็ก, ยอดซื้อรวม, ซื้อล่าสุด, ส่งออกสำหรับบรอดแคสต์ |
| ☑ A24 | คิวคำขอ PDPA (U28): ส่งออก/ลบข้อมูลลูกค้า พร้อมบันทึก |
| ☑ A25 | โน้ตภายในและงานที่ต้องทำ: ผูกกับลูกค้า/คำสั่งซื้อ, มอบหมายพนักงาน, เตือน |
| ☑ A26 | สำรองข้อมูลอัตโนมัติรายวันไปที่เก็บไฟล์ เก็บย้อนหลัง 14 วัน + กู้คืนตามคู่มือ |
| ☑ A27 | ค้นหาทั้งระบบ (Ctrl+K): คำสั่งซื้อ เอกสาร ลูกค้า สินค้า |
| ☑ A28 | ศูนย์แจ้งเตือนในหลังบ้าน: ออเดอร์/สลิป/คำขอ/เคลมใหม่ พร้อมตัวเลขยังไม่อ่าน |
| ☑ A29 | บันทึกการแก้ไขแบบก่อน/หลัง (สินค้า ตั้งค่า คำสั่งซื้อ) |
| ☑ A30 | จัดการส่วนความน่าเชื่อถือบนหน้าแรก (U30) + เรียงลำดับส่วนของหน้าแรก |
